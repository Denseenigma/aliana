Auto-scan

Runs a network scan on a schedule, using the profile selected on the dashboard (now {{ settings.profile_label }}). Automatic scans join the same queue as everything else. The first one runs a minute after switching on; after that the interval counts from the end of the last network scan.

Never-probe ports

Ports that are still reported as open but never get service-identification probes. Use this for devices that accept a connection and then go silent (e.g. door-access controllers on 9999), which otherwise stall the "Identifying services" stage and can upset small embedded devices. Takes effect from the next scan.

Default: . Comma-separate to add several at once.

Exclusions

Addresses Aliana never scans — not even a ping. Network scans skip them (nmap --exclude) and Deep scans of them are refused. Enter one IP, a range (172.16.0.10-20 or 172.16.0.10-172.16.0.20) or a block (172.16.5.0/24), with an optional note. Host cards also have an Exclude button.

Subnet size guard

Protects against accidentally scanning a huge network. Applies to every scan — dashboard, Pi screen, Queue page and auto-scan.
