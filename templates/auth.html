Erase & reset

Last resort

Use this only if you've lost both your authenticator and your recovery codes. It permanently erases:
  • RMM connection, API key and secret, and the encryption key that protected them
  • All scan history, the device inventory and identification results, the scan queue, devices heard by passive discovery, and your device labels
Kept: scan settings, exclusions, never-probe ports, and Wi-Fi networks, so the Pi stays reachable. Afterwards you'll set up a new authenticator straight away.

To prove you have the device in hand, Aliana will show a reset code on the Pi's screen.

Back to sign in

Enter the code from the Pi's screen, and type ERASE to confirm.

The reset code expires in 15 minutes. No screen? Over SSH: journalctl -u aliana | grep pairing, or run ./venv/bin/python3 auth.py --reset in the Aliana folder.
